Oprogramowanie potrzebne do uruchomienia aplikacji:
- Unity Hub,
- Unity Editor w wersji 6000.2.7f2 lub nowszej.

Wymagania sprzętowe:
- Procesor Intel Core i5-7400,
- 8GB Pamięci RAM,
- Karta graficzna Geforce GTX 1050 Ti,
- System operacyjny Windows 10/11.

Ze strony głównej Unity należy pobrać Unity Hub.

Po uruchomieniu Unity Hub należy wejść w sekcję "Installs".
Następnie kliknąć przycisk "Install Editor" i wybrać zalecaną wersję edytora 6000.2.7f2 lub nowszą.
Następnie wejść w sekcję "Projects".
Kliknąć przycisk "Add" i wybrać opcję "Add project from disk".
Wybrać wypakowany folder "2DPixelArt".
Następnie kliknąć na projekt i czekać na uruchomienie edytora.

Po uruchomieniu edytora należy z okna "Project" uruchomić scenę "MainMenu", która znajduje się w folderze "Scenes\Menu".
Aby uruchomić aplikację należy kliknąć przycisku "Play" u góry edytora.
